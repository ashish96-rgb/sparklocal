# Hackathon Presentation Outline

The editable PowerPoint is generated by `npm run build:deck` at `docs/SparkLocal-Hackathon-Deck.pptx`.

1. **SparkLocal** — Good ideas get local. A Gemma-powered community action studio.
2. **The gap** — Local problems are visible; time, roles, coordination, and a practical first step are not.
3. **The flow** — Describe the challenge; Gemma drafts a grounded action plan; neighbors share and shape the brief.
4. **Open-weight AI, meaningfully used** — Gemma generates actions, roles, supplies, outcomes, and mitigations. Ollama enables local inference; Hugging Face enables hosted inference. A labeled demo mode keeps the app accessible.
5. **Why open innovation matters** — Local knowledge is distributed. Open tools invite adaptation, inspection, collaboration, and community ownership.
6. **Real-world value and guardrails** — Low-cost first steps and measurable outcomes; community review, no sensitive-data prompt, no claim that AI replaces professional judgment.
7. **Demo and collaboration** — Show planner, shared board, join/support interaction, setup guide, MIT license, contribution guide, and community code.
8. **Next steps and links** — Add verified GitHub repository, deployed URL, demo video, and contact after publishing.

The generated deck intentionally leaves the final links generic until the repository and deployment actually exist.
