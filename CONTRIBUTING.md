# Contributing to SparkLocal

Thanks for helping make community-led projects easier to start. Contributions are welcome, including accessible UI improvements, tests, translations, documentation, model prompt evaluations, and deployment adapters.

## Before opening an issue

- Search existing issues and discussions for the same topic.
- Keep reports free of private information about community members.
- For a feature request, describe the user, the local problem, and how the change would help people collaborate.
- For a model issue, include the provider and model name, but never include API tokens or private prompts.

## Development

1. Use Node.js 20 or newer.
2. Run `npm install` and `npm start`.
3. Run `npm test` before submitting changes.
4. Keep secrets out of source, logs, screenshots, and pull requests.
5. Add or update tests when behavior changes.

## Pull requests

Open a pull request against `main` and explain the user-facing change, how it was tested, and any deployment or data implications. Keep changes focused. Contributions are made under the repository's MIT License. Maintainers may ask for revisions or decline changes that are unsafe, inaccessible, or outside the project goals.

## Community context

Do not treat AI-generated plans as professional, legal, medical, safety, or emergency advice. Prefer consent-based research, plain language, low-cost steps, accessibility, and community review. Never add features that expose participant identities or sensitive location details by default.
